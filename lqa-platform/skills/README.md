# skills

领域测试知识包（Skill）。每个技能是一个 `<id>.json` 文件，保存了团队反复用到的
领域检查要点；生成用例时勾选的技能会被注入 AI 的提示词（system + user 双通道），
让模型在通用规则之外，还掌握你的业务/项目特定知识。

## 文件格式

```json
{
  "id": "season-pass",
  "name": "赛季通行证测试要点",
  "description": "赛季体系的边界与时效检查",
  "body": "- 赛季结算边界：跨月最后一天 23:59 的归属判定\n- 奖励领取时效：过期后是否补发\n- 跨赛季叠加：未领取道具是否结转",
  "tags": ["赛季", "商城"],
  "updated_at": "2026-10-10 12:00"
}
```

- `name` / `body` 必填；`body` 会被原样注入提示词，请写成「可执行检查点」而非背景描述。
- `id` 为文件名，由界面创建时自动生成（英文/数字 slug；纯中文名会退化为
  `skill-<hash>` 形式），**不要手工改成含路径分隔符的值**。
- 目录被 git 跟踪，技能可随仓库共享给团队。

## 使用方式

1. 界面：左侧「技能库」页面新建/编辑/删除；在「生成向导」的「领域技能」区勾选。
2. 仅在勾选「启用 AI 补强」时生效——规则模式不读提示词。
3. 多个技能可叠加，同时注入。

> 说明：本目录不预置任何业务知识内容，代码里也不硬编码领域知识；
> 全部由使用者在界面中创建。
