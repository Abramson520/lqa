使用说明

本地化需求 → 可评审的 LQA 测试用例

这是什么

本地 LQA 生成工作台：把本地化需求文档/文本，变成可评审的 LQA 测试用例 Excel。 规则引擎保证无 Key 也能出可执行骨架，启用 AI 后在此骨架上补强。

主路径

  1. 打开「生成向导」，上传文档或粘贴需求
  2. 设置源语言 / 目标语言 / 条数 / 关注类别
  3. 点「分析需求」预览拆解结果
  4. 点「生成用例」；勾选 AI 补强可获得更具体的步骤与双语文案
  5. 在预览区核对后下载 Excel 或保存到 outputs/

质量门禁说明

每条用例会计算 0–100 质量分，并对空泛预期、非编号步骤、缺失双语文案等问题列入门禁明细。 规则骨架无双语文案时分数存在上限，启用 AI 补强可提升。
