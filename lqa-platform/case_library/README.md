# case_library

放置历史 LQA 用例参考文件（xlsx/md/docx/txt），页面「参考案例」会扫描本目录。

## xlsx 被当作 AI few-shot 参考样例

放入的 `.xlsx` 会被 `load_few_shots()` 读取，作为 AI 生成的参考样例（内置样例优先，案例库样例补充）。
两类列名都能识别（自动别名匹配，无需固定模板）：

- 旧「生成清单」格式：`模块` / `功能点` / `步骤` / `预期结果` / `类别` / `优先级` / `源文案` / `目标文案` / `前置条件` / `备注`
- 新「测试执行表」格式：`主模块` / `子模块` / `测试说明` / `复现路径` / `预期结果` / `前置条件` / `备注`
  - `主模块` + `子模块` 会自动拼成 `主模块/子模块` 作为 module 路径
  - 需 `主模块`+`测试说明`+`复现路径`+`预期结果` 四列齐备、且 `复现路径` ≥ 20 字才会入选

> 注意：当前仅读取 `.xlsx`（`.xls` 老二进制格式暂不支持）。放入后页面会列出该文件。
