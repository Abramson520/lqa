# LQA 生成工作台

## 项目简介

面向**游戏本地化**的「需求文档 → 测试用例」生成工作台。

输入一份 PRD / 需求文档，工作台自动产出与团队《测试执行表》格式完全对齐的本地化测试用例，并内置文本溢出、编码、占位符、文化合规等本地化专项检查。

工作台以「**规则引擎打底 + 可选 AI 补强**」双引擎驱动，并在生成前后叠加三层质量保障（缺口审查 / 质量门禁 / 覆盖率），让产出的用例**既有结构、又能追溯、还能量化质量**。

- **输入**：Word / Excel / Markdown / TXT + 粘贴文本
- **链路**：本地拆解 → 规则生成 →（可选）AI 补强 → 质量门禁 → 导出
- **输出**：Excel 用例（`outputs/时间戳_名称/`），测试执行表格式（14 列）
- **无 Key 可走规则骨架；有 Key 可 AI 补强**

## 核心特性

- **双引擎生成**：规则引擎零依赖、可离线兜底；配置 API Key 后启用 AI 补强，两者共用同一套质量与导出逻辑。
- **三层质量保障**：生成前缺口审查、生成后确定性质量门禁、需求↔用例覆盖率，全部为通用能力（词表/阈值走本模块常量，支持 `.env` 覆盖，不硬编码业务词）。
- **格式对齐团队执行表**：导出为 14 列《测试执行表》，与现有本地化用例表完全一致，可直接导入测试管理平台执行，无需二次改表。
- **领域技能库**：把团队反复用到的检查要点沉淀成技能（`skills/<id>.json`），生成时勾选即注入 AI 提示词。
- **零构建 Web 工作台**：FastAPI 后端 + 原生前端（无框架依赖），深/浅双主题，服务默认仅绑定 `127.0.0.1`。
- **关注类别自定义**：前端可添加自定义类别，生成时透传、导出优雅回退，不再被强转 `OTHER`。
- **文化合规规则拓宽**：触发维度覆盖宗教 / 政治 / 军事 / 分级 / 禁忌 / 刻板印象等通用合规项。
- **安全边界**：API Key 默认仅存于会话内存，上传文件经白名单 + 20MB 上限过滤，动态文本插入 DOM 前转义防 XSS。

## 整体架构

```
需求文档 (Word/Excel/MD/TXT/粘贴)
        │
        ▼
   parsers        解析为纯文本（utf-8-sig → gbk → utf-8 严格解码）
        │
        ▼
   analysis       拆解为原子需求点（标题 / 列表项，受 max_points 上限约束）
        │
        ▼
   gap_review     生成前缺口审查：标出 vague_point / low_testability / image_only
        │
        ▼
   rules / llm    规则引擎打底 +（可选）AI 补强 → 用例（写入 requirement_source 可追溯）
        │
        ▼
   quality_gate   生成后门禁：占位词 / 空话步骤 / 步骤-需求绑定 / 优先级分布 / 覆盖缺口
        │
        ▼
   coverage       需求点↔用例覆盖率、模块统计、高风险缺口
        │
        ▼
   exporters      映射为 14 列测试执行表 → xlsx 下载 / 落盘 outputs/
```

代码全部位于 `src/lqa/`，Web 后端 `api_server.py` 只做 HTTP ↔ `src/lqa/` 函数调用的协议转换，不复制任何业务逻辑。

## 核心模块职责

| 模块 | 职责 |
|------|------|
| `parsers` | 负责把各类输入文档统一解析为纯文本，处理编码歧义（utf-8-sig / gbk / utf-8）与格式噪声。 |
| `analysis` | 把长文本需求拆成原子需求点，支持标题、列表项两种模式，并限制最大拆解数以控制成本。 |
| `gap_review` | **生成前质量层**：扫描需求点，提前标出模糊点、低可测性、纯图片需求等源头问题。 |
| `rules` | **规则引擎**：零依赖兜底生成用例，覆盖本地化常见缺陷类别，确保无 Key 也能跑通。 |
| `llm` | **AI 补强引擎**：调用外部大模型生成/评审用例，支持多 Provider 与领域技能注入。 |
| `quality_gate` | **生成后质量层**：确定性校验用例质量，输出占位词、空话、绑定缺失、优先级失衡等 Issue。 |
| `coverage` | **覆盖质量层**：统计需求点 ↔ 用例的覆盖关系，定位高风险缺口。 |
| `exporters` | 把内部用例模型映射为团队标准的 14 列《测试执行表》Excel。 |
| `api_server` | Web 工作台后端，只做协议转换，所有业务逻辑复用 `src/lqa/`。 |
| `web` | 零构建单页前端，负责上传/配置/生成/预览/下载的交互界面。 |
| `skills` | 领域技能库，把项目/业务特定的检查要点沉淀为可复用的 JSON 知识包。 |

## 质量层（三层保障）

| 层 | 模块 | 时机 | 作用 |
|----|------|------|------|
| 生成前缺口审查 | `src/lqa/gap_review.py` | 生成前 | 扫描需求点，标出源头问题（`vague_point` / `low_testability` / `image_only`） |
| 生成后质量门禁 | `src/lqa/quality_gate.py` | 生成后 | 确定性校验：占位词、空话步骤、步骤-需求绑定、优先级分布、覆盖缺口，统一输出 Issue 结构 |
| 需求-用例覆盖率 | `src/lqa/coverage.py` | 生成后 | 需求点↔用例覆盖率、模块统计、高风险缺口 |

`generate()` 统一回传 `gap_review` / `quality_issues` / `coverage` 三类产物及其 Markdown，`exporters.save_output(reports=...)` 可落盘《覆盖率报告.md》《需求缺口审查.md》《质量门禁.md》。

## 导出格式

导出为团队统一的**测试执行表**，与现有本地化用例表完全对齐，可直接导入测试管理平台执行。

| 列 | 来源 | 说明 |
|----|------|------|
| 用例编号 | 自动生成 | `LOC-001` 递增（前缀可配，默认 `LOC`） |
| 主模块 / 子模块 | `module` 按 `/` 拆两级 | 无斜杠时主模块保持原值、子模块留空 |
| 测试说明 | `feature` | 缺失时由功能点 + 类别合成一句 |
| 前置条件 / 复现路径 | `preconditions` / `steps` | 多行统一规范为 `1.2.3.` 编号换行（点后无空格） |
| 入口截图 / 测试截图 | — | **留空**，执行时补图 |
| 本地化检查项 | `category` 派生 | 通用 4 条 + 类别特有项，编号换行 |
| 预期结果 | `expected` | 缺失时回退到「本地化检查项」 |
| 实际结果 / 测试人 / 不通过原因 / 测试环境 | — | **留空**，由执行人填写 |
| 备注 | `notes` | 原样透传 |

设计边界：导出层只做**字段映射**，不改生成与质量逻辑；执行期字段一律留空，不臆造执行结果。

## Web 工作台

Web 工作台是面向使用者的图形化入口，负责把「上传/粘贴 → 分析 → 生成 → 预览 → 下载」整条链路串成一键式流程。

**设计原则**：后端不复制任何业务逻辑，仅做 HTTP 与 `src/lqa/` 函数之间的协议转换；前端为零构建单页应用，深浅双主题、拖拽上传、进度可视化、用例搜索与详情抽屉、模型连通性探测、Toast 通知等全部内聚在 `web/` 中。

**关键能力**：
- **用例条数不限制**：`count` 为 0 或不填时按需求充分生成、不做截断；填正整数则作为上限。
- **关注类别自定义**：除内置类别外，使用者可在前端添加自定义类别，生成时透传、导出时优雅回退。
- **领域技能注入**：在生成向导勾选技能后，技能内容会同时写入 system/user 提示词，提升模型对业务知识的遵从度。
- **文化合规拓宽**：CULTURAL 类别触发维度覆盖宗教、政治、军事、分级、禁忌、刻板印象等通用合规项。
- **优雅退出**：通过 `api_server.py` 直接启动时，`/api/shutdown` 可释放端口；也提供 `stop_web.bat` 一键停止。

浏览器访问地址：**http://127.0.0.1:8788**

## 技能库（领域测试知识包）

把团队反复用到的领域检查要点沉淀成**技能**，生成时勾选即可注入 AI 提示词——让模型在通用规则之外，还掌握你的业务/项目特定知识。

- **技能库页面**：新建 / 编辑 / 复制式修改 / 删除，落盘为 `skills/<id>.json`，随 git 共享给团队
- **多选叠加**：生成向导中可同时勾选多个技能
- **生效条件**：仅在勾选「启用 AI 补强」时生效（规则模式不读提示词）

```json
// skills/season-pass.json
{
  "id": "season-pass",
  "name": "赛季通行证测试要点",
  "body": "- 赛季结算边界：跨月最后一天 23:59 的归属判定\n- 奖励领取时效：过期后是否补发",
  "tags": ["赛季", "商城"]
}
```

内置机制不含任何业务知识，领域内容全部由使用者在界面创建（详见 `skills/README.md`）。



## 安全边界

本工具定位为**本地单人使用**，未引入鉴权，请知悉：

- 服务默认仅绑定 `127.0.0.1`，不对外网暴露
- API Key **默认只存在于本次会话内存**，不自动写入磁盘；勾选「保存到 .env」才会明文落盘，届时会显式提示
- 所有接口响应中的 Key 一律**脱敏**（如 `sk-a…xyz`），不回传明文
- 上传文件经扩展名白名单过滤，并有 20MB 体积上限防止大文件吃内存
- 前端所有动态文本插入 DOM 前均经转义，避免来自文档/AI 输出的内容造成 XSS

> 中文任务名导出 Excel 时，`Content-Disposition` 采用 RFC 6266（ASCII 回退名 + `filename*=UTF-8''<百分号编码>`），否则会因 HTTP 头不支持非 latin-1 字符而报错。
